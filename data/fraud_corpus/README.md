# Fraud pattern corpus

Sixteen **anonymized, rewritten** case summaries inspired by public
auto-insurance fraud indicator research (including feature families found
in the widely used Kaggle "Automobile Insurance Claims Fraud" teaching
set) and published NICB-style pattern bulletins.

No Kaggle row is copied. No real claimant, VIN, or claim number appears.
Each file is a pattern description the fraud agent can retrieve and cite.
