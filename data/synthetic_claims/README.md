# Synthetic claims (prompt-dev pool)

Generated by `uv run python scripts/generate_synthetic_data.py`.

Each `data/synthetic_claims/<claim_id>/` folder has:

- `claim.json` — structured FNOL (ground-truth labels **stripped** so they
  cannot leak into prompt iteration)
- `documents/fnol-claim-form.pdf`
- `images/*.jpg` — labeled placeholder damage photos with EXIF
- `notes.txt` — clean, messy, or contradictory adjuster notes

The labeled holdout is **only** under `data/eval_set/`. See `SPLIT.json`.

Photos are synthetic diagrams, not CarDD stills (CarDD is research-licensed
and not redistributable in this repo).
