# Demo capture

The live walkthrough is http://localhost:3001 (see the root README).

To attach a 90-second recording when you publish the repo:

1. Start API, worker, and `apps/frontend` (`npm run dev` on port 3001).
2. macOS QuickTime Player → File → New Screen Recording.
3. Submit `PA-2026-000039 · hail`, wait for the verdict, scroll the timeline.
4. Save as `docs/demo/claimguard-demo.mp4` and link it from the README.
